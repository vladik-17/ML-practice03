## Назначение и модель

Программа прогнозирует прочность бетона на сжатие (МПа) по восьми характеристикам смеси из датасета Concrete. Используется подвыборка из 400 объектов, `seed=12` и разбиение 70/30, как в практической работе № 2.

Доступны две регрессионные модели: линейная регрессия со стандартизацией и случайный лес. Модель выбирается в выпадающем списке. Для линейной регрессии в прошлой работе получены RMSE около 9,58 МПа и R² около 0,701 на тестовой выборке.

## Архитектура

- `ml/` — загрузка и вызов модели; не импортирует PySide6.
- `services/` — разбор строки признаков и форматирование результата; не импортирует PySide6.
- `desktop/` — интерфейс PySide6 и фоновый `QThread`.
- `models/` — сохранённые артефакты `joblib`.

Расчёт запускается в `PredictWorker(QThread)`. Рабочий поток возвращает результат в GUI сигналом `finished_ok` или текст ошибки сигналом `failed`, поэтому окно остаётся отзывчивым.

## Установка и запуск

Для фиксированных в задании версий зависимостей используйте Python 3.10–3.12.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python train_models.py
python -m desktop.main
```

`train_models.py` создаёт артефакты моделей в `models/`. Датасет `Concrete_Data.csv` должен находиться в корне проекта.

В VS Code можно открыть `desktop/main.py` и запустить его кнопкой ▶.

## Ввод

В окне есть восемь отдельных полей с названиями признаков и единицами измерения. При запуске они заполнены примером из датасета. Любое значение можно изменить. В дробных числах можно использовать запятую или точку.

Нажмите «Предсказать» для расчёта прочности. Кнопка «Очистить» сбрасывает все поля. Если поле пустое или вместо числа введён текст, под кнопками появится сообщение об ошибке.
