Дисциплина: Методы и алгоритмы машинного обучения

Тема: Десктопное приложение для ML-классификации/регрессии на PySide6 с сигнал-слот взаимодействием

Форма отчёта: репозиторий или архив с README.md + файл docx (можно сделать в Pandoc)

Цель работы

Освоить на практике построение десктопного ML-приложения на PySide6, в котором:

  1. ML-модель (классификация или регрессия) изолирована в отдельном модуле и не зависит от GUI;
  2. длительный ML-вызов выполняется в фоновом потоке QThread;
  3. результат возвращается в GUI через пользовательский сигнал (Signal) и слот (Slot), без блокировки интерфейса.

Базовая практика: возьмите любую лабораторную работу из курса (построение 1-2 моделей для маленького датасета). Желательно, в которой вы обучали модель классификации или регрессии на scikit-learn. Сохранённую модель (joblib) используйте как артефакт для этого задания.

2. Требования к структуре проекта

Проект должен содержать слои архитектуры. ML-ядро и сервис не должны импортировать PySide6.

Примерная структура (ориентироваться, но спроектировать самостоятельно):

ml_app/
├── config.py
├── requirements.txt
├── models/
│   └── classifier.joblib
├── ml/
│   ├── __init__.py
│   ├── model_loader.py
│   └── predictor.py
├── services/
│   ├── __init__.py
│   └── prediction_service.py
└── desktop/
    ├── __init__.py
    ├── main.py
    ├── main_window.py
    └── worker.py

Файл requirements.txt должен фиксировать версии:

scikit-learn==1.5.*
joblib==1.4.*
PySide6==6.7.*

3. Задания

3.1. Обязательная часть

Задание 1. Каркас проекта и ML-ядро

  1. Создайте структуру каталогов из раздела 3.
  2. Перенесите обученную в предыдущей практике модель в models/ через joblib.dump().
  3. Реализуйте ml/predictor.py с классом Predictor, который:
    • загружает модель в конструкторе;
    • проверяет количество признаков (n_features_in_);
    • возвращает словарь с полем prediction и, если доступно, proba.
  4. Реализуйте services/prediction_service.py с классом PredictionService, который парсит строку вида "5.1, 3.5, 1.4, 0.2" и возвращает строку-результат.

Критерии защиты:

  1. модули ml/ и services/ не содержат import PySide6.
  2. У приложения есть структура.

Задание 2. Главное окно

Реализуйте desktop/main_window.py с классом MainWindow(QMainWindow), содержащим:

Виджет Назначение Настройка
QLineEdit Ввод признаков setPlaceholderText("Признаки через запятую")
QPushButton «Предсказать» Запуск ML clicked.connect(on_predict_clicked)
QPushButton «Очистить» Сброс полей clicked.connect(on_clear_clicked)
QLabel Результат setText("Результат появится здесь")

Компоновка — через QVBoxLayout внутри QWidget, установленного как setCentralWidget().

Задание 3. Фоновый поток и сигналы

  1. Реализуйте desktop/worker.py с классом PredictWorker(QThread), содержащим:
    • сигналы finished_ok = Signal(str) и failed = Signal(str);
    • переопределённый run(), который вызывает PredictionService.run() и испускает соответствующий сигнал.
  2. В MainWindow.on_predict_clicked():
    • блокируйте кнопку «Предсказать» (setEnabled(False));
    • устанавливайте QLabel в состояние «Вычисление...»;
    • создавайте PredictWorker, соединяйте его сигналы со слотами on_success и on_error;
    • запускайте поток через start().
  3. В слотах on_success и on_error обновляйте QLabel и разблокируйте кнопку.

Критерии защиты: во время выполнения ML-вызова окно можно перетаскивать, кнопка недоступна, по завершении — результат отображается и кнопка снова активна.

Задание 4. Проверка отзывчивости

  1. Временно добавьте в PredictWorker.run() задержку time.sleep(2) перед вызовом сервиса.
  2. Запустите приложение и убедитесь, что интерфейс не «замерзает»: окно перемещается, кнопка визуально заблокирована.
  3. Уберите задержку.

Задание 5. Обработка ошибок

Проверьте, что приложение не падает и выдаёт понятное сообщение в QLabel в случаях:

  • нечисловой ввод ("abc");
  • неверное количество признаков ("1, 2" при n_features=4);
  • пустая строка.

4.2. Дополнительная часть (на оценку «отлично»)

Задание 6. Выбор модели

Добавьте QComboBox с двумя моделями (например, «Логистическая регрессия» и «Random Forest»). При смене значения (currentIndexChanged) сигнал должен переключать Predictor в PredictionService.

Задание 7. Визуализация вероятности

Для классификации расширьте Predictor.predict() так, чтобы он возвращал proba. Передавайте вероятность через дополнительный сигнал Signal(float) в QProgressBar (0–100 %).
